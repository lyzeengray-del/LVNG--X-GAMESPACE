# LVNG -X Game Space (Android Cloud Build)

Project Android lengkap dengan desain **Biru Tua & Merah Crimson (LVNG -X)**, panel mengambang (*Floating Window*) minimalis di atas game, **Macro Auto-Tap** dengan pemilih koordinat langsung di dalam game (`🎯 SET TITIK`), **FPS Boost & Monitor**, **Audio FX**, dan **Virtual Crosshair**.

## Cara Build Jadi APK Otomatis di GitHub Actions
1. Buat repository baru di GitHub (misalnya `LVNG-X-GameSpace`).
2. Upload seluruh isi folder `LVNG-X_GameSpace` ke branch `main`.
3. Buka tab **Actions** pada repository GitHub kamu.
4. Pilih workflow **Build LVNG-X Game Space APK** lalu klik **Run workflow**.
5. Tunggu hingga selesai, buka hasil run tersebut, lalu download artifact **`LVNG-X-GameSpace-debug-APK`**.
6. Ekstrak file ZIP artifact dan install `.apk` di HP Android kamu.
